# 이미지 출처

| 파일 | 내용 |
| --- | --- |
| `demo-home.jpg` | 공개 데모 홈페이지 캡처 |
| `demo-submit.jpg` | 공개 데모 사진 제출 화면 캡처 |
| `demo-organizer.jpg` | 가상 회원과 샘플 그래픽을 사용하는 Organizer 캡처 |
| `demo-editor.jpg` | 가상 회원과 샘플 그래픽을 사용하는 Editor 캡처 |
| `original-submit.png` | 기존 서비스의 사진 제출 화면, 입력 전 상태 |

스크린샷은 원본 비율로 표시합니다. 실제 회원 정보가 담긴 관리자 화면과 제출 사진은 포함하지 않았습니다.

- `public/images/home-main.jpg`: 기존 서비스의 메인 배경 사진. 픽셀과 크기를 유지하고 EXIF 메타데이터만 제거했습니다.
- `public/samples/`: 데모용으로 코드로 작성한 SVG 그래픽입니다.
- `public/`의 로고 이미지: LUMINAR 프로젝트의 브랜드 자산입니다.

로고와 사진의 권리는 원저작자에게 있습니다.
