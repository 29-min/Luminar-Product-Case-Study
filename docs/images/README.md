# 화면 자료와 공개 범위

| 파일 | 출처·성격 | 공개 처리 |
| --- | --- | --- |
| `original-submit.png` | 제작자가 제공한 기존 서비스 사진 제출 화면, 입력 전 | 회원 사진·실명·SNS 계정이 보이지 않는 원본을 비율 변경 없이 복사 |
| `demo-home.jpg` | 이번에 구성한 공개 데모의 실제 브라우저 캡처 | 운영 홈페이지로 표현하지 않음 |
| `demo-submit.jpg` | 공개 데모의 실제 브라우저 캡처 | 입력 전 상태 |
| `demo-organizer.jpg` | 공개 데모의 실제 브라우저 캡처 | 가상 회원·코드로 작성한 샘플 그래픽 |
| `demo-editor.jpg` | 공개 데모의 실제 브라우저 캡처 | 가상 명단·코드로 작성한 샘플 그래픽 |

원본 스크린샷을 잘라내거나 비율을 바꾸지 않습니다. README의 이미지는 자연 비율로 표시합니다. 데모 캡처는 실제 브라우저 렌더링 결과이며 이미지 생성으로 만든 UI가 아닙니다.

기존 Organizer·Editor 캡처에는 실명·SNS 계정·회원 사진이 있어 포함하지 않았습니다. 이름 익명화만으로 사진 저작권과 인물 공개 동의 문제가 해결되지는 않으므로, 공개 동의 확인 전에는 보류합니다. 기존 홈페이지 전체 원본 캡처는 포함하지 않았습니다. 메인 배경 사진은 제작자의 사용 요청에 따라 기존 서비스의 `main02.jpg`를 사용하며, EXIF 메타데이터만 제거했습니다. 픽셀과 원본 비율은 유지합니다.

`public/images/home-main.jpg`는 기존 서비스의 메인 배경 사진입니다.

`public/samples/`는 이 공개본을 위해 코드로 작성한 SVG 그래픽입니다. 실제 동아리 활동 사진이나 운영 데이터가 아닙니다. `public/`의 로고 3개는 기존 프로젝트의 브랜드 자산이며, 독립적인 재사용 허가를 부여하지 않습니다.
