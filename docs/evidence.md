# 구현 근거와 표현 범위

검토 기준은 기존 비공개 저장소의 로컬 사본 `ee6f2a6`과 접근 가능한 22개 커밋입니다. 비공개 원본 링크나 인증정보는 공개 문서에 포함하지 않습니다. 로컬 원격 추적 브랜치가 GitHub 서버의 최신 상태와 같음을 별도로 검증하지 않았습니다.

| 주장 | 근거 | 표현 범위 |
| --- | --- | --- |
| 약 70명 규모 동아리의 운영 문제 | 제작자 경험 설명 | 실제 활성 사용자 수가 아님 |
| 2024 GAS MVP 시작 | 제작자 설명, 별도 GAS 코드 사본 | 시작 연도를 Next.js 커밋으로 검증한 것은 아님 |
| 본인 1인 개발·디자이너 1명 협업·운영진 QA | 제작자 설명 | 개별 커밋과 특정 피드백의 인과관계는 확인되지 않음 |
| 사진 제출·분류 | 기존 `UploadForm`, upload API, Drive 유틸 | 코드 구현 확인, 이번 작업에서 실서비스 업로드 재현은 하지 않음 |
| CORS 대응과 서버 업로드 | 개발 로그와 현재 upload API | 현재는 브라우저 직접 Drive 업로드가 아님 |
| OAuth2 인증 | 현재 `lib/auth.ts`, `89815e4` | 과거 문서의 Service Account가 현재 구조는 아님 |
| 폴더 중복 생성 완화 | `2552a31`, 폴더 초기화와 Promise 공유 | 분산 환경 전체의 보장이 아님 |
| 이미지 최적화 | 기존 Canvas 리사이즈 코드 | 가로 폭 1,920px, JPEG 0.82. 성능 수치는 미측정 |
| 사진 조회·정렬·명단·ZIP | 기존 Organizer·PhotoGrid·SubmitterList | 정렬의 서버 영구 저장은 확인되지 않음 |
| 표지 편집·출력 | 기존 Editor·Fabric.js·JSZip, `ee6f2a6` | SNS 자동 게시 기능은 아님 |
| 공개 갤러리 | 과거 커밋, `d0b7b24`의 제거 이력 | 현재 독립 갤러리 기능으로 소개하지 않음 |
| Map | 지도 코드와 제작자의 중단 설명 | 공개본에서 제외한 실험 |
| 수동 업무 단계 대체 | 제작자의 운영 설명과 자동 분류 구현 | 실제 사용 횟수·절감 시간·만족도 미측정 |

공개본의 코드 위치는 [architecture.md](architecture.md)에 정리했습니다. 공개본 홈페이지는 새로 구성했으며 Organizer·Editor는 기존 화면과 구현을 바탕으로 데이터 연결·일부 안내·폰트·접근성 처리를 조정했습니다.
