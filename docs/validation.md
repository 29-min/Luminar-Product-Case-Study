# 검증 기록

검증일: 2026-10-21 (Asia/Seoul). 공개 후보만 대상으로 검증했으며, 기존 운영 서버에 업로드하거나 Drive 권한을 변경하지 않았습니다.

## 빌드·구성

- TypeScript 검사: `npm run typecheck` 통과.
- Next.js 프로덕션 정적 빌드: `npm run build` 통과. `/`, `/submit/`, `/organize/`, `/editor/` 생성.
- `app/api`, `app/map`, OAuth/Drive 서버 모듈 및 `googleapis` 의존성 없음.
- 패키지 잠금 파일을 별도 임시 디렉토리에서 `npm ci --dry-run --ignore-scripts --offline`으로 검증. 잠금 파일과 의존성 일치 확인.
- 로컬 빌드는 기존에 설치된 의존성을 연결해 사용했습니다. 네트워크에서 의존성을 새로 받는 완전한 clean install은 수행하지 않았습니다. 연결된 `node_modules`는 공개 패키지에 포함하지 않습니다.
- `npm run check:public`으로 현재 공개 후보의 주요 비밀 패턴·운영 연결·금지 경로·README 링크를 점검합니다. Git 이력이나 사진 권리의 완전한 감사는 아닙니다.

## 실제 브라우저 확인

| 항목 | 확인 내용 |
| --- | --- |
| 홈페이지 | 제품 소개와 제출·Organizer·Editor 진입 링크 |
| 기본 데이터 | 가상 회원, 날짜/조 폴더, 샘플 그래픽 8장 |
| 제출 | 개인정보 없는 테스트 JPG 1장 선택, 날짜·조·가상 이름·출사지 입력, 로컬 저장 성공 |
| 이미지 축소 | 2,400×1,600 테스트 JPG가 1,920×1,280으로 저장되고 Blob URL로 표시됨 |
| 자동 분류 | 날짜/조 폴더, `테스트회원-1-데모공원.jpg` 형식 파일명 확인 |
| 영속성 | 전체 페이지 이동과 새로고침 뒤에도 추가한 날짜 폴더와 사진 유지 |
| 정렬 | 카드 드래그 후 명단 순서 변경, Editor URL과 사진 목록에 변경 순서 전달 |
| Editor | 장소 텍스트 수정, 날짜·조·명단 자동 입력, 샘플 이미지 렌더링 |
| 표지 JPG | 실제 파일 다운로드 후 JPEG 형식·2,160×2,700 크기·GPS 태그 없음 확인 |
| 사진 ZIP | 샘플 사진과 표지를 묶는 처리 후 다운로드 Blob 링크 생성 확인. ZIP 파일을 내려받아 압축 해제하는 검증은 수행하지 않음 |
| 초기화 | 테스트 제출 폴더와 사진이 사라지고 기본 샘플만 남는 것을 확인 |
| 화면 범위 | Manager는 데스크톱 전용. 1,440×1,000에서 확인하며 모바일 지원은 범위에서 제외 |
| 콘솔 | 주요 체험 과정에서 확인한 오류 로그 없음 |

브라우저의 네이티브 저장 대화상자 의존성을 제거하고 일반 다운로드와 Editor의 재다운로드 링크를 제공합니다. 자동 다운로드가 차단되면 표시된 링크를 사용하세요. 입력 라벨 연결, 이미지 Blob URL 정리, 선택 그룹 변경 중 이미지 비동기 응답 처리도 보완했습니다. 카드의 앞/뒤 이동 버튼으로 키보드 정렬도 가능합니다.

## 자료 검증과 한계

- 공개본 이미지에 GPS 태그가 없음을 확인했습니다. 기존 회원 사진 폴더는 복사하지 않았습니다.
- 기존 실제 화면은 입력 전 사진 제출 화면만 포함했습니다. 이름·SNS 계정·사진 권리가 걸린 다른 운영 캡처는 보류했습니다.
- 기존 비공개 저장소 작업 트리에 변경 없음. Git 이력·원격 설정·운영 자격증명에 변경 없음.
- iOS Safari·Android 실기기, 여러 탭 동시 편집, 저장 공간 고갈, 모든 이미지 형식·손상 파일, 보조 기술 전체를 검증한 것은 아닙니다.
- 성능 개선률·운영비·활성 사용자·만족도를 새로 측정하지 않았습니다.
- 이 기록은 로컬 공개본 검증을 다룹니다. 호스팅 배포 검증은 포함하지 않습니다.

## 후속 UI 수정

- Editor의 출사지 이름 옆 색상 선택 버튼과 사용하지 않는 Toolbar 색상 변경 연결을 제거했습니다.
- 홈페이지 배경을 제작자 요청에 따라 기존 서비스의 메인 사진으로 변경했습니다. 사진의 픽셀·원본 비율은 그대로 보존하고 EXIF만 제거했습니다.
- README와 이미지 출처 설명, 홈페이지·Editor 캡처 및 공개 후보 ZIP을 함께 갱신했습니다.

- Organizer 카드 이름을 `이름-사진번호` 형식으로 표시하도록 수정하고 실제 브라우저에서 확인했습니다. 사진 정렬 순번과 별도로 원래 사진 번호를 유지합니다.
- README를 작성자 시점의 프로젝트 소개로 다듬고, 반복적인 검토 문구는 상세 근거 문서로 분리했습니다.
